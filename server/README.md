# Phương Anh Backend

Minimal REST API for the Phương Anh rental clothes storefront.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm start`

## Notes

- The server includes a mocked product/category/booking dataset.
- Image upload supports a 5MB max file size.
- CORS is enabled for the Vite frontend on port 5173.
